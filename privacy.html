隱私權政策 Privacy Policy

最後更新:2026-10-07

historyremix-analytics 是 YouTube 頻道「歷史課本 Remix」經營者自用的工具，不對外提供服務。

  • 讀取什麼:經頻道擁有者本人授權後，以唯讀權限(youtube.readonly、yt-analytics.readonly)讀取本頻道的影片清單與成效數字，例如觀看次數、觀看時間、流量來源。
  • 如何使用:只用於頻道經營者自己分析內容成效。
  • 存在哪裡:資料與授權憑證只存在頻道經營者自己的電腦上，不上傳到任何伺服器。
  • 是否分享:不出售、不分享、不轉交給任何第三方。
  • 其他使用者:本工具不讀取、不蒐集任何其他 YouTube 使用者的個人資料。
  • 撤銷授權:可隨時在 Google 帳戶的第三方存取權設定 撤銷。

本工具對 Google API 取得資料的使用遵守 Google API Services User Data Policy,包括其中的 Limited Use 規定。

historyremix-analytics is a personal tool used solely by the owner of the "歷史課本 Remix" YouTube channel. With the owner's authorization it reads that channel's own video list and analytics (read-only scopes). Data and credentials are stored only on the owner's computer, are never sold or shared with third parties, and no other users' data is collected. Access can be revoked at any time at Google Account permissions. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
